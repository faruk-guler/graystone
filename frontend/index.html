        Import hosts
        
    
        One per line: host, host:port or name host. Blank and # lines are skipped; an existing name is updated, not duplicated. Or load the list from a file.
        
    
    
        
      
      
      
      
    
        
          
  
  
    
        Add forwards from a line
        
    
        One forward per line, in the form you would type for ssh or read in PuTTY's list: L 9080 db.internal:5432, -R 2222 localhost:80, -D 1080. A leading ssh and a # note are fine; *:2222:localhost:80 asks the server to bind every interface. Each line opens a forward over the session on screen.
